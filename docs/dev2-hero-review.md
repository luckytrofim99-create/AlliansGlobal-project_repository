# Dev2 — первый экран агентства

28 октября 2026. Эта правка заменяет образовательный первый экран из предыдущего обзора компоновки. Раздел образования остаётся сразу под ним.

## Результат

Первый экран следует предоставленному пользователем примеру: «Ваше будущее — без границ», фотография Рима через арку, описание виз, ВНЖ, ПМЖ, гражданства и юридической помощи. Основная кнопка «Обсудить мою задачу» ведёт к форме, дополнительная ссылка — к услугам. Капсульные кнопки сохранены.

По прямому запросу пользователя добавлено УТП «Юридическая гарантия соблюдения сроков». Уточнение связывает сроки с собственной работой агентства и договором. УТП стоит перед основной кнопкой.

Полная навигация и мобильное меню теперь доступны на главной и внутренних страницах. На узких экранах переключение языка находится внутри меню. Сохранены закрытие Escape, возврат фокуса и переходы по разделам. Шапка сохраняет капсульную форму при прокрутке.

## Проверки

- Проверены все 34 уникальные страницы через DOM браузера при ширинах 1440 и 390px: 80 вхождений фото на каждой ширине, все находятся в скруглённых рамках. Основной радиус — 24px и 18px соответственно; верх фото главного экрана сохраняет арку. Горизонтальный выход не обнаружен.
- Просмотрены главный экран и карточки журнала. Финальная production-сборка главной просмотрена при ширинах 1440, 768 и 390px; дополнительно проверена ширина 320px. Заголовок занимает две строки. На планшете исправлен перенос тире на отдельную строку.
- Проверены открытие меню на главной, RU/EN, Escape, возврат фокуса и переход в журнал. Основной CTA ведёт к форме на главной. При ширине 1150px навигация после прокрутки помещается внутри капсулы.
- ESLint, TypeScript и production-сборка прошли. HTTP smoke финальной сборки: 35 запросов страниц, 37 ресурсов, четыре проверки настоящего 404.
- Проверка адаптивности выполнена в браузере с изменённой шириной окна. Физические устройства не использовались. Локальный детектор impeccable недоступен; выполнена ручная проверка по существующей визуальной системе и референсу пользователя.

Рабочий просмотр остаётся на http://127.0.0.1:3002/. Временный production-сервер использовался только для проверки.
