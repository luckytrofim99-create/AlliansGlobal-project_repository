# Alliance Global

Многостраничная концепция сайта международного консалтинга. Next.js 16, React 19, TypeScript, Motion и Web Animations API. Шрифты и изображения хранятся локально.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://localhost:3000. Для собранной версии: `npm run build`, затем `npm start`.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
npm test -- http://localhost:3000
```

Последняя команда проверяет запущенный сайт: маршруты, заголовки, язык, noindex, ресурсы, передачу страны в консультацию и настоящие HTTP 404.

## Содержание

- Главная в новом визуальном языке: бумажный фон Idadu, коллаж из актуального Figma-макета: чёрно-белые фотографии, багажные бирки, штамп, красный принт и самолёт, мягкие элементы управления по принципам Apple. Услуги сменяются по скроллу и свайпу; ручной выбор сохраняется. Страны и жизненные цели ведут к соответствующим подробным страницам. На главной нет основного меню, счётчиков глав, декоративных лозунгов и диагональных стрелок; на внутренних страницах меню сохранено.
- Общая визуальная система главной и всех внутренних страниц: бумажный фон, тёмный сине-зелёный `#0D2734`, золотой `#B19365`, крупные заголовки и мягкие фотографические поверхности.
- Пять услуг и страницы каждой. Визы дополнены фотографической историей с существующей графикой документов.
- Семь направлений: региональные фильтры, поиск, страницы стран и передача выбранной страны в форму.
- Программы, компания, подход, журнал и четыре статьи, консультация, контакты, конфиденциальность, 404.
- Мобильное меню внутренних страниц с нативным диалогом, FAQ на `details/summary`. Короткая форма QuickConsultation переиспользуется на главной и странице консультации: Telegram или телефон, выбор страны и задачи, локальный TXT-черновик. Ссылки поддерживают `?country=` и `?goal=`.
- Анимация слов, раскрытие фотографий и мягкое движение изображений при обычном скролле. При уменьшении движения фотографии статичны; серверный контент видим и без JavaScript.

Тексты и данные — `lib/content.ts`, общие стили — `app/globals.css`. Главная, её тема и переиспользуемые анимации — `components/home/`; общие внутренние композиции, каталог и фотографические сцены — `components/pages/`. Старые компоненты Globe и TravelDossier сохранены в исходниках, текущие маршруты их не используют. Исходники коллажа и геометрия слоёв — `public/images/home-figma/manifest.json`. Источники фото — `public/images/sources.json`, описания сгенерированных объектов — `public/images/journey-assets.json` и `journey-wallet-source.json`. Шрифты Idadu, лицензии OFL и происхождение — `public/fonts/idadu/`; фон и его источник — `public/images/idadu/`. Work Sans и Anton из референса не содержат кириллицу: русский текст использует Manrope. Материалы заказчика сохранены в `agents/` и корне проекта. Концепция Superdesign — `.superdesign/`.

## Перед рабочим запуском

Форма сейчас **не отправляет заявки**: данные остаются в памяти страницы, пользователь может скачать локальный черновик. Никакие CRM, почта, аналитика или внешние формы не подключены.

Нужно получить реальные контакты и реквизиты, подтвердить перечень стран и услуг, согласовать юридические тексты, условия консультации и обработку обращений. Команда, партнёры, отзывы и кейсы намеренно не выдуманы. Статьи о подготовке не содержат утверждений об актуальных условиях иммиграционных программ.

Прототип закрыт от индексации через metadata и robots.txt. Перед публикацией задать `NEXT_PUBLIC_SITE_URL`, подготовить окончательную политику конфиденциальности, подключить отправку и согласовать индексацию.

## Структура проекта

```text
app/                        страницы, маршруты, общий layout и стили
components/                 компоненты, форма, глобус и анимации
components/home/            главная, бумажная тема, общая форма и движение
components/pages/           внутренние страницы, каталог, шапка и фотосцены
lib/content.ts              тексты и данные сайта
public/images/              изображения и sources.json
scripts/smoke.mjs            HTTP-проверка запущенного сайта
.github/workflows/ci.yml     CI для PR в main и dev
docs/github-setup.md         защита веток и будущие CI/CD secrets
```

Материалы `agents/`, `.superdesign/`, `artifacts/`, локальные env и конфиги с секретами исключены из Git. Локальные файлы для работы агента не требуются для запуска сайта.

## CI

Workflow `CI`, job/check **`ci`** запускается на Pull Request в `main` и `dev`: checkout → Node.js 22 → `npm ci` → lint → build. Отсутствующие lint/build пропускаются через `--if-present`; ошибки существующих скриптов завершают CI с ошибкой. Развёртывания на хостинг нет.

Сейчас CI не требует пользовательских secrets. Правила защиты и перечень необязательных секретов для будущего CI/CD описаны в [docs/github-setup.md](docs/github-setup.md).
